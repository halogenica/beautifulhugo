# Upgrade Beautiful Hugo v5.0 to v5.1

v5.1 adds post preview thumbnails on list pages, moves related posts to Hugo's
related-content engine, and translates the last hardcoded UI strings. It also
removes the unused Font Awesome stylesheets and makes `false` work for some
parameters. The minimum Hugo version does not change (0.146.2).

Do the steps in order. Step 1 is required for every site. Steps 2 to 7 apply only
if the check command finds something.

## 0. Baseline

```bash
git status --short          # commit or stash first
hugo --minify               # build v5.0 once
cp -r public /tmp/before-v5-1
```

## 1. Point the site at v5.1 (required)

The module path does not change.

**Hugo module**

```bash
hugo mod get -u github.com/halogenica/beautifulhugo/v5
hugo mod tidy
```

**Git submodule**

```bash
git -C themes/beautifulhugo fetch --tags
git -C themes/beautifulhugo checkout v5.1.0
git add themes/beautifulhugo
```

**Copy in `themes/`** — replace the directory with the v5.1 source.

## 2. Add a `[related]` block

Applies to sites with `Params.showRelatedPosts = true`.

Related posts now come from Hugo's related-content engine. A site without a
`[related]` block falls back to Hugo's default ranking, which uses `keywords` and
`date` and ignores tags. To keep tag-driven suggestions, add to the **site**
configuration:

```toml
[related]
  includeNewer = true
  threshold = 80
  toLower = false
  [[related.indices]]
    name = "tags"
    weight = 100
  [[related.indices]]
    name = "keywords"
    weight = 80
  [[related.indices]]
    name = "date"
    weight = 10
```

## 3. Check the new list-page thumbnails

List pages now show `thumbnail`, or `image` when `thumbnail` is unset, as a
thumbnail beside the post snippet. In v5.0 the same `image` value rendered as a
full-width picture, so pages with a wide banner image look different.

```bash
grep -rln '^image:\|^thumbnail:' content | head
```

- To keep a page's preview image, do nothing.
- To hide the preview image for one page, set `thumbnail: ""` in the front matter.
- A page with neither key still shows a video preview, if it has one.

## 4. Confirm `false` values that now take effect

`ghCount: false` and `showPageDates: false` were ignored in v5.0, because Hugo's
`default` reads `false` as unset. v5.1 honours them.

```bash
grep -rn 'ghCount\|showPageDates' hugo.toml content | grep -i false
```

A site that set `false` and still saw the GitHub count or the page dates now loses
them. That is the documented behaviour. Delete the parameter to get the feature
back.

## 5. Update Font Awesome names and links

v5.1 loads one `all.css` file and deletes the other Font Awesome files from the
theme, including `v4-shims.css`. Three v4 icon names are renamed.

```bash
grep -rn 'fa-adjust\|fa-times\|fa-search\|fontawesome/css/' layouts assets static hugo.toml
```

- `fa-adjust`, `fa-times`, and `fa-search` become `fa-circle-half-stroke`,
  `fa-xmark`, and `fa-magnifying-glass`.
- A `<link>` to a theme file such as `fontawesome/css/brands.css` gets a 404.
  Delete the tag; `all.css` covers every style.
- Other v4 icon names in custom templates no longer work, because the shim file is
  gone. Use the v7 name.

## 6. Add the new translation keys

Applies to sites with an override in `i18n/`.

These keys are new: `tagsLabel`, `tocLabel`, `tocPostsLabel`, `tocCloseLabel`,
`breadcrumbHomeLabel`, `paginationPageLabel`, `termPagesTitle`,
`termPagesDescription`, `taxonomyPagesTitle`, `taxonomyPagesDescription`.

```bash
for k in tagsLabel tocLabel tocPostsLabel tocCloseLabel breadcrumbHomeLabel \
         paginationPageLabel termPagesTitle termPagesDescription \
         taxonomyPagesTitle taxonomyPagesDescription; do
  grep -rq "$k" i18n || echo "missing: $k"
done
```

A missing key falls back to English, so this step is optional for an English site.

## 7. Refresh copied theme templates and custom gallery markup

```bash
ls layouts/partials layouts/_default layouts/shortcodes 2>/dev/null
```

Diff each copy of a theme file against the v5.1 version and port the local edits.
These templates changed the most: `head.html` (no `X-UA-Compatible`, pinch-zoom
allowed, `https` schema.org types, RSS link from the output format, a title suffix
when `homeTitle` is unset), `post_preview.html` (thumbnails), `related.html`, and
the TOC and search partials.

Custom markup that opens PhotoSwipe must emit `data-pswp-width` and
`data-pswp-height`; the loader no longer reads `data-size`.

```bash
grep -rn 'data-size' layouts assets static content
```

## 8. Build and compare

```bash
hugo --minify --panicOnWarning
diff -rq /tmp/before-v5-1 public | head -40
```

Check by hand: list-page previews, related posts, the table-of-contents panel,
search, image galleries, and the navbar icons.
