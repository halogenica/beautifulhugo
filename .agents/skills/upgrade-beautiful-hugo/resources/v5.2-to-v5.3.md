# Upgrade Beautiful Hugo v5.2 to v5.3

v5.3 loads the site file `assets/css/custom.css` automatically, adds the
`webFonts` parameter, and shows a series box on posts in a `series` taxonomy. The
minimum Hugo version does not change (0.146.2).

Step 1 is required for every site. Steps 2 and 3 apply only if the check command
finds something.

## 1. Point the site at v5.3 (required)

Use the commands from step 1 of `v5.1-to-v5.2.md` with the tag `v5.3.0`.

## 2. Check for an existing `assets/css/custom.css`

The theme now links `assets/css/custom.css` on every page, after all theme CSS and
before `head_custom.html`. A site that already has a file at that path gets it
loaded automatically.

```bash
ls assets/css/custom.css 2>/dev/null
grep -rn 'custom\.css' layouts hugo.toml config 2>/dev/null
```

If the file exists:

- **The site links it from `head_custom.html` on every page** — delete that tag.
  The theme link replaces it.
- **The site links it only on some pages, or passes it through
  `resources.ExecuteAsTemplate` or another pipe** — rename the file (for example
  to `assets/css/site.css`) and update the site link, so the theme does not also
  load the raw file.
- **The file comes from another imported module** — the theme loads it too. Mount
  it at a different path if that is not wanted.

A `static/css/custom.css` file is not affected.

## 3. Check for an existing `series` taxonomy

The theme now shows a series box at the top of each post that is in a `series`
term with two or more posts. The series term pages (`/series/<name>/`) now list
their posts in series order (`series_weight`, then oldest first) and not newest
first.

```bash
grep -rnE '^\s*series\s*[=:]' hugo.toml config 2>/dev/null
grep -rn 'series' layouts 2>/dev/null
```

If the site declares the taxonomy:

- **The site has its own series navigation** (for example in
  `before_content.html`) — delete it, or set `Params.seriesPosition = "none"` to
  keep the old output.
- **The site does not want the box** — set `Params.seriesPosition = "none"`.
- **Posts already use `series_weight` for another purpose** — the value now sets
  the order of the series and must be a number.

## 4. Build and compare

```bash
hugo --minify --panicOnWarning
grep -o '<link[^>]*custom[^>]*>' public/index.html
grep -rlc 'class="series-box"' public | head
```

Expect one `custom` stylesheet link at most. Expect series boxes only if the site
wants them.

## 5. Optional: adopt the new v5.3 features

- **Site stylesheet** — move `<style>` blocks from `head_custom.html` into
  `assets/css/custom.css`.
- **Own fonts** — `Params.webFonts = false` stops the Lora and Open Sans
  stylesheet. Set the fonts in `assets/css/custom.css`.
